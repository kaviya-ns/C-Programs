# C Programs

A collection of beginner-to-intermediate C programs solving everyday problems — finance, geometry, unit conversion and arrays.

![C](https://img.shields.io/badge/C-00599C?logo=c&logoColor=white)

## Programs

| Topic | Programs |
|---|---|
| **Arrays** | array basics, array reversal |
| **Finance** | account balance, interest rate, simple & compound interest, discount amount |
| **Math & Science** | roots of a quadratic equation, trigonometric angles, voltage gain, math tutor |
| **Conversions** | Celsius ↔ Fahrenheit (direct and with loops) |
| **Everyday problems** | pizza slices, number of pizzas ordered, parking-lot fee (functions) |
| **Structures** | `struct` usage |

All sources are in [`c programs/`](c%20programs).

## Compile & run

```bash
gcc "c programs/roots of quadratic equation.c" -o quadratic -lm
./quadratic
```
